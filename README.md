Este es un software para manipular las salas de cómputo de una institución la cual tiene en su base de datos toda la información de sus profesores y estudiantes.

El programa se encarga de crear, leer, actualizar y eliminar tanto profesores como estudiantes mediante la pestaña "admin" a la cual se accede desde el menú de login colocando las credenciales "admin","123".

También digita toda la información de los registros que hay en la base de datos

mismas funcionalidades para los profesores

El programa puede identificar que tipo de usuario eres desde la pantalla de login con el fín de mostrar la información correspondiente de cada usuario.

Si eres profesor te mostrará la interfaz para prestar salas de computo solo en tus horas de clase establecidas.

Si eres estudiante te mostrará la interfaz para prestar computadores portatiles solo si eres estudiante de Ing. Sistemas

Aun no se ha terminado y faltan algunas validaciones, pero, con el avance que se ha visto podemos presenciar que es un proyecto con futuro y escalable a algo más grande.
